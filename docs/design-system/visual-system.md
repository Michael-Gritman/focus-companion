# Visual System — confirmed direction

User selections confirmed on 2026-09-13. This records visual decisions; it does not claim implementation or prototype acceptance.

## Selected

- Primary button: B-2. Strong 2.5D action; reference face height 58, radius 14, bottom depth 8, press travel 7. Reference width is not a fixed global width.
- Surface: S-2. Warm light surface, subtle boundary and slight shadow. Reference radius 20. Use elevation selectively.
- Typography: T-1. Nunito for Latin text and numbers; Noto Sans SC is the current Chinese companion, not a final custom Chinese brand typeface.
- Density: D-2. Spacious composition; reference mobile page padding 28, approximately 32 between major content groups.
- Status chips: C-1. Light fill with explicit status text; color alone never conveys state.
- Bottom navigation: N-1. Quiet navigation with restrained active emphasis. Home / Time Pool / More.

## Still undecided

- Bottom navigation icons: explicitly pending; user intends to explore app-specific icons in Rive. Do not treat previous icon samples as approved.
- Brand palette: graphite and warm white remain temporary. Success green is semantic, not the brand color.
- Character, distinctive brand expression, final page composition, motion, haptics, and sound.

## Product constraints

- Home is the action center; Time Pool is the growth center.
- One dominant action per state; an active restriction replaces the start action.
- Completion adds the original session duration once. Result-viewing never credits it again.
- Early exit consumes the remaining duration only if the pool is sufficient; no negative balance.
- Rules are recurring definitions, separate from restriction sessions.
- Penpot interactions are a prototype. They do not implement app blocking, persistent balances, live timing, or editable forms.
